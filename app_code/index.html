Что, кто, зачем и для чего (Справка)
1. Зачем нужно это приложение?
Это автономная мини-среда разработки на iPhone. Ты пишешь код, собираешь файлы и картинки в структуру и прямо без интернета упаковываешь всё в готовый установочный файл .ipa.
2. Как работают Python и pip-пакеты?
Во вкладке «3. Python / pip» ты вписываешь названия нужных библиотек (например, numpy, requests). Они вшиваются в requirements.txt и подгружаются в проект через WebAssembly-движок без вылетов LiveContainer.
3. Что такое Bundle ID и зачем его менять?
Это уникальный паспорт приложения (например, com.tigran.game1). Если оставить одинаковый Bundle ID, LiveContainer спросит: заменить старое или поставить как новое (Install as new).
4. Как синхронизировать проекты через iCloud?
Внутри любого проекта нажми «Сохранить в iCloud» и выбери папку iCloud Drive в «Файлах». Файл будет доступен на всех твоих устройствах Apple.
